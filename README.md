# МАФ Каталог для SketchUp

Тестовое расширение для SketchUp Desktop 2021–2026 на Windows и macOS. Показывает статистику моделей МАФ в проекте, находит кандидатов в дубли и помогает хранить компоненты в личной, общей локальной и облачной библиотеках.

## Установка

1. Скачайте [maf_library-0.11.2.rbz](dist/maf_library-0.11.2.rbz).
2. В SketchUp откройте **Extensions → Extension Manager → Install Extension** и выберите файл `.rbz`.
3. Откройте **МАФ Каталог** кнопкой на панели инструментов SketchUp. Панель инструментов можно перетащить и закрепить в удобном месте; пункт **Extensions → МАФ Каталог** также доступен.

Архив пока не подписан для Extension Warehouse. Для локального тестирования SketchUp может запросить разрешение на загрузку неподписанного расширения.

## Новое в версии 0.4.0

По умолчанию меняется только выбранная модель. Совпадающие группы тоже участвуют в анализе. Объединение групп преобразует их в компоненты и поддерживает Undo.

## Новое в версии 0.3.0

- В библиотеке доступны теги, избранное, недавние модели и поиск по названию, категории и `#тегу`. Избранное облачных моделей хранится в личных настройках.
- Карточки показывают размер файла, а после загрузки модели в SketchUp также габариты и число граней. При числе граней свыше 200 000 показывается предупреждение. Для ещё не загруженных `.skp` эти показатели пока неизвестны. При публикации облачного каталога размер файла записывается автоматически. Дополнительные поля можно задать в JSON-файле рядом с `.skp`: `tags`, `bbox_mm`, `faces_count`, `edges_count`, `materials_count`.
- Для массового добавления поместите `.skp` в `<папка библиотеки>/inbox/<раздел>/` и нажмите **Проверить папку**. Плагин скопирует модели в управляемое хранилище. Повторная проверка сохраняет ID; переименование файла без изменения содержимого также сохраняет ID. Удаление файла из `inbox` не удаляет запись каталога.
- Кнопка **Экспорт видимых** сохраняет отфильтрованные модели выбранной личной или общей библиотеки в папку с `pack.json`. **Импорт подборки** читает такую папку, проверяет SHA-256 и пропускает уже имеющиеся файлы. ZIP-упаковка не требуется.
- Из карточки модели можно запустить раскладку **По линии** или **По поверхности**. Задайте шаг 100–10 000 мм, наведите курсор для предпросмотра точек и нажмите в сцене для размещения. Линия задаётся двумя кликами; поверхность — одним кликом по грани в корне модели. Лимит — 250 экземпляров за операцию; вся раскладка отменяется одним Undo.

Предпросмотр раскладки показывает точки вставки. Работу инструмента в SketchUp нужно проверить на целевых версиях приложения; автоматические тесты выполняются вне SketchUp и проверяют только расчёты и работу с файлами.

## Возможности версии 0.2.1

- Анализ запускается кнопкой **Анализировать** внутри панели. После завершения рядом с кнопкой показывается длительность проверки.
- В списке моделей выбор одной строки сохраняется и при вложенных компонентах. На странице дублей можно выбрать одно или несколько определений и сфокусировать на них камеру SketchUp.

- **Проект:** подсчет размещений компонентов, в том числе вложенных, отдельных определений и кандидатов в дубли. Щелчок по строке выделяет соответствующие компоненты в сцене; Ctrl/Cmd и Shift позволяют выбрать несколько строк. Если компонент вложен, выделяется доступный в текущем контексте контейнер.
- **Действия по правому клику:** добавить выбранные модели в личную или общую библиотеку, переименовать одно определение, назначить раздел, удалить размещения или заменить их выбранным эталоном. Удаление и замена поддерживают Undo.
- **Разделы:** предустановлены «Скамейки», «Урны», «Светильники», «Площадки», «Другое»; новые разделы создаются в панели.
- **Миниатюры:** SketchUp пытается создать изображение при добавлении компонента. Для другого ракурса можно прикрепить PNG/JPEG/WebP или вставить снимок из буфера. Ограничение файла — 5 МБ.
- **Хранилища:** личная и общая папки выбираются отдельно в настройках. Общую папку можно расположить на сетевом диске. Облачный каталог подключается по HTTPS, синхронизируется по кнопке, а `.skp` загружается при первом размещении и проверяется по SHA-256.
- **Обновления:** кнопка проверяет последний GitHub Release, скачивает архив нужной версии, сверяет размер и SHA-256 и передает его штатному установщику SketchUp с подтверждением.
- **Очистка:** панель показывает число неиспользуемых определений и групп дублей. Массовая очистка пока не запускается из расширения.

## Облачная библиотека

Первая версия облачного режима работает на чтение: участник команды может синхронизировать каталог и размещать модели, если у него есть доступ к HTTPS-файлам. Добавление из SketchUp сохраняет модель в личную или общую локальную папку; публикация в облако выполняется владельцем каталога. Токены GitHub расширение не запрашивает и не хранит.

Для GitHub-публикации:

1. Положите модели в `cloud-library/models/<раздел>/<имя>.skp`. Необязательные изображения — в `cloud-library/thumbnails/<раздел>/<имя>.png` (также подходят `.jpg` и `.webp`).
2. Запустите `python3 scripts/build_cloud_manifest.py`. Скрипт создаст `cloud-library/manifest.json` с адресами файлов и контрольными суммами.
3. Опубликуйте эти файлы в доступном команде репозитории. Если он отличается от данного, передайте скрипту `--base-url https://raw.githubusercontent.com/<owner>/<repo>/<branch>/cloud-library`.
4. В настройках расширения укажите URL опубликованного `manifest.json` и нажмите **Синхронизировать**.

В репозитории лежит пустой пример манифеста. Пока в него не добавлены `.skp` и файлы не опубликованы, синхронизация покажет ноль моделей. Для закрытого каталога потребуется отдельный способ авторизации; текущий вариант рассчитан на URL, доступный участникам без входа.

## Релизы и обновление

Актуальный [GitHub Release v0.6.8](https://github.com/oreshkinns/sketchup---model-library/releases/tag/v0.6.8) содержит архив `maf_library-0.6.8.rbz`, собранный из исходников проекта. Номер тега, `VERSION` в `maf_library.rb` и имя архива должны совпадать. Кнопка **Проверить обновления** в панели загружает последний опубликованный релиз и проверяет размер и SHA-256 архива перед установкой.

В версии 0.6.8 сохранение выделенного компонента и создание его копии выравнивают X/Y вдоль сторон основания, сохраняют Z вверх и переносят начало координат в нижний угол габаритов. Изменяется библиотечная копия; физическая форма и размер выбранного экземпляра сохраняются. Для неоднозначной, содержащей изображения или слишком сложной геометрии поворот сохраняется с предупреждением. Анализ основания ограничен по объёму.

В SketchUp 2023+ для обычных сохраняемых копий создаётся ортографическая миниатюра с азимутом 45° и подъёмом около 35,3°, вмещающая компонент целиком. Она записывается в `.skp` и PNG библиотеки. Кнопка пересоздания извлекает изображение из сохранённого файла, поэтому изменения размещённого экземпляра не подменяют картинку библиотечной модели и не затрагивают Undo/Redo. Старые и импортированные файлы сохраняют встроенную картинку до явного пересохранения выбранной копии. Автоматическое восстановление карточек, динамические компоненты без изменения геометрии и SketchUp 2021–2022 используют штатную миниатюру без принудительного ракурса. Уже сохранённые модели автоматически не перезаписываются.

Версия 0.6.7 сохраняет выбранный экземпляр с его физическим масштабом, включая масштаб родительских компонентов и групп. Размеры карточки и сохранённого `.skp` берутся из одной экспортной геометрии; исходная геометрия проекта не меняется. Обычный поворот не меняет размеры сохраняемого определения.

Ранее сохранённые карточки автоматически не исправляются. Если старая карточка увеличена, выделите нужный экземпляр в модели и используйте **Создать копию выделенного…**. Для масштабного варианта число размещений показывается как неизвестное, если связь с исходным определением не доказывает совпадение сохранённой геометрии. Автоматический экспорт масштабированных определений требует явного выбора экземпляра. Небезопасная замена масштабным вариантом и обновление из масштабированных размещений блокируются с объяснением.

В версии 0.6.6 миниатюры полностью помещаются в рамку, исправлены кнопки размещения для нативного API SketchUp. Большие списки открываются только в активном разделе порциями по 100 элементов; кнопки **Назад** и **Далее** переключают порции. Переходы между разделами не запускают анализ.

## Ограничения и проверка

- Поиск дублей сравнивает геометрию, вложенные компоненты и часть материалов, но не все свойства SketchUp и сторонних расширений. Каждая группа требует визуальной проверки перед заменой.
- Остановка анализа обрабатывается между шагами. Если SketchUp уже сохраняет один компонент или его миниатюру в библиотеку, это нативное действие должно завершиться до отклика кнопки.
- В SketchUp 2021 экспорт компонента из проекта использует `save_as`, потому что `save_copy` появился в SketchUp 2022. Это может обновить путь определения; сам проект не сохраняется автоматически.
- Права записи в общую локальную папку и доступность облачного адреса зависят от окружения пользователя.
- Код проверен локальными тестами Ruby и проверкой синтаксиса. Ручное испытание в SketchUp 2021–2026 на целевых системах еще требуется.

```bash
ruby test/test_core.rb
bash build.sh
```

API: [SketchUp Ruby API](https://ruby.sketchup.com/), [GitHub Releases API](https://docs.github.com/en/rest/releases/assets).

## Локальное распознавание и библиотека

Панель открывается на странице **Библиотека**. **Добавить выделенный в SketchUp** читает текущее выделение при нажатии, без предварительного анализа: выберите один компонент или группу, затем укажите название, раздел и личную или общую библиотеку в диалоге SketchUp. Пункт контекстного меню SketchUp открывает тот же процесс. **Добавить файл .skp** импортирует файл отдельно. При существующей связи с выбранной библиотекой открывается карточка без нового файла. Для другой библиотеки используйте отдельную кнопку **Создать копию выделенного…**: исходная карточка остаётся, а новая копия получает отдельный файл.

Анализ работает локально: использует подтверждение пользователя, связь с каталогом, полный отпечаток и консервативные правила по именам, габаритам, геометрии и особенностям компонента. Кандидат не является подтверждённым МАФ. В **Обзоре → Распознавание и параметры** показаны причины, предупреждения, имена, теги, размеры, геометрия, вложенность и особенности. Можно подтвердить МАФ, отклонить его или сбросить ручное решение. Неполная и выборочная геометрия не доказывает точное совпадение.

Новый подтверждённый МАФ автоматически сохраняется **один раз в личную библиотеку** как `.skp`; повторный анализ и полный точный матч используют существующую карточку. Общая и облачная библиотеки автоматически не меняются. При нескольких точных карточках показывается неоднозначность без произвольной связи и без отнесения размещений к конкретной карточке. Чтобы создать отдельную однозначную запись, выделите один экземпляр в SketchUp и используйте **Создать копию выделенного…**. Выбор существующей карточки для ручной привязки отдельным действием пока не поддерживается.

Изменение геометрии не перезаписывает сохранённый файл. Карточка показывает расхождение; **Обновить версию…** предлагает явно выбрать связанное определение и подтвердить сохранение новой версии. Ошибка записи сохраняет отчёт и показывает причину с кнопкой повтора. Карточки показывают раздел, габариты, грани, рёбра, материалы, размер файла, SHA-256, версию, источник и размещения. **В текущем проекте: —** означает, что свежего отчёта нет; **0 размещений** означает подтверждённое отсутствие в текущем проекте. Эти числа не хранятся в манифесте.

Отмена служебной привязки сохраняет Redo. Для восстановления после сохранения и повторного открытия проекта личная библиотека хранит отдельный индекс в `recovery/`: он связывает путь и сохранённую ревизию проекта с постоянным ID определения и карточкой. Индекс содержит только связь, поэтому неполная геометрия остаётся непроверенной. Успешное сохранение и **Сохранить как** обновляют индекс даже при закрытой панели; до первого сохранения связь хранится в памяти. Перемещение файла вне SketchUp, замена проекта другим файлом или перенос одной библиотеки без индекса не доказывают старую связь: восстановите постоянную привязку перед переносом проекта с неполной сигнатурой. Ошибка сохранения индекса требует повторного анализа до закрытия проекта.

В SketchUp 2025–2026 отпечаток учитывает числовые настройки PBR-материалов, включая шероховатость и металличность. Дополнительные карты шероховатости, металличности, нормалей и затенения, как и обычная текстура без сравнения пикселей, делают отпечаток неполным и запрещают автоматическое точное совпадение. После обновления расширения старый отпечаток PBR-модели может потребовать явного обновления версии карточки.

В **Обзоре** одинаковые определения объединяются только внутри одной ветки дерева. Фильтр **Только МАФ** сохраняет родителей как путь к МАФ. Непомеченные группы служат контейнерами. Показатели **Все компоненты** и **МАФ** отдельно показывают размещения и определения; подтверждённые группы входят в МАФ. Родитель и вложенный МАФ учитываются отдельно. Перед действиями **со всеми размещениями** показываются общее количество и пути по проекту; выбор ветки не ограничивает операцию этой веткой. После изменения отчёта открытое подтверждение нужно открыть заново. Разделы используют `is_maf`, как отчёт и CSV; CSV также содержит источник и причину распознавания.

### Автоматическая проверка интерфейса

```sh
npm install
npx playwright install chromium
npm test
ruby -e "Dir['test/test_*.rb'].sort.each { |file| require File.expand_path(file) }"
bash build.sh
```

UI-тесты используют `node:test` и Playwright 1.62.1. Для готового окружения можно задать `NODE_PATH` на каталог с установленным Playwright; `MAF_UI_FILE` позволяет тем же тестам открыть извлечённый `maf_library/ui.html` из RBZ. Сборка требует Ruby, Bash и `zip`. Браузерные и Ruby-тесты вне SketchUp не подтверждают работу HtmlDialog, нативного диалога, сохранения `.skp` и Undo — выполните [ручную приёмку](docs/sketchup-acceptance.md).
