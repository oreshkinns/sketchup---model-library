# МАФ Каталог 0.7.0 — галерея и удаление из библиотеки

Навигация перенесена наверх, библиотека открывается компактной галереей. В стандартном окне четыре колонки моделей, в минимальном — две. Поиск и фильтры видны сразу, список моделей прокручивается отдельно.

**Добавить** открывает сохранение выделенного в SketchUp, импорт `.skp` и создание копии. В меню **⋯** находятся проверка папки, импорт/экспорт подборок, тема и замена выделенного. Параметры, изображения и раскладка моделей доступны через **Подробнее**.

В личной и общей библиотеке добавлено **Подробнее → Удалить из библиотеки…** с подтверждением названия и библиотеки. Размещения в проекте не удаляются. Сохранённый `.skp`, миниатюра и метаданные остаются на месте; карточка отмечается `removed_at` и исключается из каталога. Анализ и проверка папки её не восстанавливают, в том числе после Undo привязки и изменения геометрии. Явное добавление модели снова доступно. Облачная библиотека остаётся доступной только для чтения.

Проверки: 323 Ruby-теста, 5238 утверждений; 42 UI-теста, включая готовый RBZ; грамматика JavaScript ECMAScript 2018 для CEF 64; совпадение упакованного интерфейса с исходником. Один существующий тест символических ссылок `test_import_rejects_symlinked_asset_and_export_preserves_existing_folder` недоступен без привилегии создания symlink в Windows: полный запуск показал EACCES; остальные Ruby-тесты прошли отдельно. Нативная приёмка этой версии внутри SketchUp не выполнялась.

После установки сохраните проект и перезапустите SketchUp.
