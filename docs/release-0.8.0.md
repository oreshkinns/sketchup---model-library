# МАФ Каталог 0.8.0 — разделы, дубли, очистка и виды библиотеки

- **Библиотека:** список или карточки трёх размеров; выбранный вид сохраняется. В меню **Подробнее** карточки можно изменить её раздел в личной или общей библиотеке.
- **Разделы:** удаление пустого пользовательского или встроенного раздела с подтверждением. Занятые разделы защищены: сначала перенесите относящиеся к ним модели. Служебный раздел **Другое** удалить нельзя.
- **Дубли:** таблица сравнивает превью, имя определения, габариты, геометрию и число размещений. Превью первой небольшой группы загружаются автоматически; остальные — по кнопке. Если миниатюра недоступна, отображается соответствующая отметка. Только совпадение полной доступной сигнатуры подтверждает дубль; неполные проверки остаются кандидатами без автоматической замены. После изменения модели сравнение блокируется до нового анализа.
- **Очистка:** после анализа можно выбрать неиспользуемые определения, не имеющие вложенных экземпляров, и удалить их после подтверждения. Перед удалением выполняется повторная проверка, операция поддерживает Undo. Материалы, теги и скрытая геометрия не удаляются.

Архив совместим с существующим механизмом обновления плагина. После установки сохраните проект и перезапустите SketchUp.

Проверено: 329 Ruby-тестов и 47 UI-тестов, включая UI из готового RBZ; JavaScript проверен на грамматику ECMAScript 2018. Один существующий тест символических ссылок исключён: Windows не разрешает создание symlink без дополнительных прав. Нативная проверка версии в SketchUp не выполнялась.
