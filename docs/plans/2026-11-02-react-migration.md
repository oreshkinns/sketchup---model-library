# Перенос интерфейса на React — 2026-11-02

Запрос: перенести текущий интерфейс на React без редизайна и изменения функций; подготовить компоненты для дальнейшей замены пользовательскими.

Решения: локальная сборка React 18, совместимая с CEF64; самостоятельный preview.html и тот же файл как maf_library/ui.html внутри RBZ. Сохранить Ruby callback API, window.MAF.receive, текущие стили и области безопасности подтверждений. Не менять алгоритмы и данные Ruby. Реальные React-компоненты представлений, а не оболочка вокруг HTML-строк.

Порядок:
1. Выделить исходники, компоненты и сборку React.
2. Перенести представления, сохранив обработчики и ограничения подтверждения.
3. Включить сборку в обе команды упаковки.
4. Прогнать существующие UI/Ruby тесты и новые проверки React/offline, визуальное сравнение и HtmlDialog в SketchUp.
5. Собрать проверенный RBZ и описать точки замены компонентов.

Авторизация: пользователь явно запросил реализацию без изменения дизайна; ранее просил проверять и выпускать обновления. Повторное согласование того же направления не требуется.
