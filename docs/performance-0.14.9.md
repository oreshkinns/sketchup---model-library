# Проверка производительности 0.14.9

Дата: 7 ноября 2026, Windows. Сравнение с 0.14.8 на одинаковых искусственных данных. Числа ниже относятся к указанным операциям, а не ко времени анализа любого пользовательского проекта.

| Операция и данные | До | После |
| --- | ---: | ---: |
| 100 полных отпечатков одной грани с 90 сторонами | 4,321 с | 1,291 с |
| 5 полных отпечатков сетки из 200 треугольников с общей вершиной | 2,492 с | 1,554 с |
| Построение индексов и поиск 1000 строк среди 1000 карточек, 10 проходов | 1,139 с | 0,0093 с |
| Поиск связей для 100 видимых карточек среди 100 000 строк проекта | 62,41 мс | 2,90 мс |
| Данные обновления одной карточки в каталоге из 1000 моделей, превью по 50 КБ | 66 814 922 байта | 66 836 байт |
| Записи каталога при одном размещении | 2 | 1 |

Отпечатки и результаты поиска в сравнении совпали полностью. Кэши граней и вершин живут только в пределах одного прохода и удерживают сами объекты, чтобы исключить повторное использование Ruby object_id. Новый проход после редактирования заново читает геометрию. Проверки материалов, текстур, исходного SHA-256, полноты геометрии, неоднозначных совпадений и изменений размещённых компонентов сохранены.

Перед каждой задачей уже работающего фонового рендера удалён второй таймер на 100 мс. Время запуска SketchUp и экспорта изображения зависит от модели и нагрузки ПК; устойчивый процент ускорения полного рендера по этим замерам не заявляется. Изображения до и после побайтно совпали: 512×512, фон с alpha=0, геометрия с alpha=255. Начальная загрузка библиотеки по-прежнему передаёт все превью; сокращение объёма данных относится к последующим изменениям отдельной карточки.

Дополнительно исправлена потеря области библиотеки при автоматическом рендере. CatalogManager каждый раз создаёт отдельный объект Catalog, поэтому сравнение объектов через equal? не могло определить personal/shared. Теперь область передаётся явно; повторная постановка карточки в очередь сохраняет исходное задание и ревизию, а завершение обновляет именно её изображение.

Нативные проверки SketchUp 2021.0.339 и 2025.0.634: синхронный и пошаговый расчёт отпечатков совпадает с 0.14.8, редактирование обнаруживается; исходные SKP, камера, выделение и Redo сохраняются. Полный путь Controller → CatalogManager → очередь → отдельный SketchUp → публикация проверен на личной и общей карточках с одинаковым ID. Пользовательские проекты не открывались и не сохранялись тестами.

Вспомогательные замеры и нативные результаты находятся локально в `.tools/perf0149/` (исключено из Git). Повторяемые регрессионные тесты включены в `test/`. Архитектура, разрешение изображений и точность анализа не упрощались ради скорости.
