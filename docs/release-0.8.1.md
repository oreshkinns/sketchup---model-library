# МАФ Каталог 0.8.1 — новый значок

Значок панели инструментов заменён на выбранный синий куб-каталог с тремя полками. Подготовлены изображения для маленькой и большой панели инструментов SketchUp.

После установки перезапустите SketchUp, чтобы обновить значок. Настройки и библиотеки сохраняются.

Проверены размеры 24 × 24 и 32 × 32, прозрачность, содержимое архива и 3 теста панели инструментов. Внутри SketchUp версия не проверялась.
