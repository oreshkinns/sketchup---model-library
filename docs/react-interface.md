# React-интерфейс

Исходники находятся в `frontend/`. Собранный `preview.html` — результат сборки, его не следует редактировать вручную.

## Компоненты для замены

- `frontend/App.jsx`: каркас приложения, навигация, шапка, страницы библиотеки, обзора, дублей, разделов, очистки и настроек, контекстное меню и диалог действий.
- `frontend/components.jsx`: `CatalogCard`, `ModelTreeRow`, `RecognitionCard`, `DuplicateCard`, `DuplicateActions`, `PlacementGroup`, `SectionRow`, `CleanupRow`. Это JSX-компоненты представлений; здесь можно менять визуальную структуру отдельных карточек и строк.
- `frontend/styles.css`: существующая палитра, типографика, размеры и адаптивные правила.
- `frontend/main.jsx`: локальный запуск React.
- `frontend/viewHost.jsx`: синхронное обновление React-представлений для совместимости с текущим мостом SketchUp.
- `frontend/runtime.jsx`: координация состояния, фильтры, выбор, предпросмотры, обработчики действий и `window.MAF.receive`. Ruby продолжает передавать те же данные и получать те же callback-команды.

При замене компонентов нужно сохранить их входные props, контейнеры с `id` и атрибуты `data-*`, через которые координационный слой обрабатывает действия. Если новые компоненты имеют другой API, адаптируйте их props и события в этом слое; не меняйте Ruby-протокол ради визуального оформления. Текст названий моделей выводится React как текст, без HTML-инъекции.

## Сборка и проверка

```sh
npm ci
npm run build
npm test
```

Сборка включает React 18 и React DOM в самостоятельный HTML; CDN не используется. Целевой движок — Chrome/CEF 64, соответствующий ранним поддерживаемым версиям SketchUp. Установленному расширению Node.js не нужен.

Для упаковки используйте `scripts/build.ps1` на Windows или `bash build.sh`. Оба скрипта запускают React-сборку и кладут результат в `maf_library/ui.html` внутри RBZ.

UI-тесты проверяют прежние действия и ограничения подтверждений, реальный React-рендеринг при обновлении данных, работу без запросов к интернету и безопасный вывод названий. `MAF_UI_FILE` позволяет прогнать те же тесты по HTML, извлечённому из готового архива.
